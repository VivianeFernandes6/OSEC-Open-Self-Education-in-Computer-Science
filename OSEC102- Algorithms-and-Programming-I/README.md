# OSEC102 — Algorithms and Programming I

## Course Description

Introduction to programming and algorithmic problem-solving using Python.

The course develops fundamental programming skills, focusing on computational thinking, algorithm construction, data representation, and structured programming.

## Learning Objectives

- Understand fundamental programming concepts.
- Develop algorithmic thinking and problem-solving skills.
- Learn Python syntax and semantics.
- Work with variables, data types, and operators.
- Implement conditional and repetition structures.
- Develop and use functions.
- Understand fundamental data structures.

## Topics

1. Introduction to Programming
2. Variables and Data Types
3. Input and Output
4. Type Conversion
5. Arithmetic and Logical Operators
6. Conditional Statements
7. Loops
8. Functions
9. Data Structures

## Repository Organization

- `exercises/`: Programming exercises developed throughout the course.
- `projects/`: Practical projects developed using the concepts studied.
