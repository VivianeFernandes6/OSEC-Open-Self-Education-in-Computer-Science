# Open Self-Education in Computer Science (OSEC)

A structured, self-directed Computer Science curriculum designed to build a strong foundation in computing, programming, mathematics, and problem-solving.

## About

OSEC is a personal academic learning project inspired by traditional Computer Science curricula.

It combines theoretical study, programming exercises, practical projects, and independent research to develop fundamental knowledge and practical skills in Computer Science.

## Objectives

- Build a strong foundation in Computer Science.
- Develop computational and algorithmic thinking.
- Learn programming and problem-solving techniques.
- Study mathematics and logic applied to computing.
- Develop practical programming skills through exercises and projects.
- Document academic progress and practical work.

- Weekly workload: 7 hours.
- Learning format: Self-directed study.
- Methodology: Theoretical study, programming exercises, practical projects, and review.
