# Open Self-Education in Computer Science (OSEC)

A structured self-education curriculum in Computer Science.

## Objective

Build a solid foundation in Computer Science through
theoretical studies, programming exercises and practical projects.

## Curriculum

| Course | Subject | Status |
|---|---|---|
| OSEC101 | Introduction to Computing and Problem Solving | In progress |
| OSEC102 | Algorithms and Programming I | In progress |
| OSEC103 | Mathematics and Logic for Computing I | Not started |

## Study Schedule

- Weekly workload: 7 hours
- Format: Self-directed study
