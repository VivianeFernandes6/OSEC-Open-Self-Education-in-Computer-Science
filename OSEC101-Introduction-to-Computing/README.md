# OSEC101 — Introduction to Computing and Problem Solving

## Course Description

Introduction to fundamental Computer Science concepts, computational thinking, algorithmic problem-solving, and the representation of information.

The course focuses on understanding how computational problems can be analyzed, represented, and solved through logical and systematic approaches.

## Topics Covered

### 1. Introduction to Computing
- Introduction to Computer Science.
- Difference between Computer Science and Programming.
- Problem-solving fundamentals.

### 2. Input, Processing, and Output
- Input, Processing, and Output concepts.
- Identifying these stages in computational problems.

### 3. Algorithms and Pseudocode
- Definition and purpose of algorithms.
- Algorithms as step-by-step instructions.
- Pseudocode as a representation of problem-solving logic.

### 4. Binary Representation
- Binary and decimal number systems.
- Bits and bytes.
- Binary-to-decimal conversion.

### 5. Control Structures
- Conditional statements.
- Repetition structures.
- Introduction to algorithmic flow control.

### 6. Algorithm Efficiency
- Introduction to algorithm comparison.
- Basic understanding of algorithm efficiency.
- Introduction to Selection Sort.
